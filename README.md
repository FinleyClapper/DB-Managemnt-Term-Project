# 🎵 (RHYTHMIX)

MUSICDATA (public name: **RHYTHMIX**) is a database-driven web application that allows users to:
- Explore Spotify track metadata
- Search songs by title, artist, or genre
- Create and manage playlists with real persistence
- Analyze cultural trends through award and genre data

---

## 🚀 Features
- **Song Search**: Query tracks by keywords and filters
- **Playlist Management**: Create playlists, add/remove songs, track counts
- **Genre & Award Data**: Explore artist genres, award nominations, and wins
- **Real Database Persistence**: Powered by MySQL with normalized schema
- **Flask Backend**: RESTful routes and APIs for seamless integration
- **Frontend Templates**: Dynamic rendering with Jinja2

---

## 🛠️ Tech Stack
- **Backend**: Python (Flask, SQLAlchemy ORM/Core)
- **Database**: MySQL Community Edition
- **Frontend**: HTML, CSS, Jinja2 templates
- **DevOps**: Docker for containerization, GitHub for version control
- **Tools**: MySQL Workbench, VS Code

---
